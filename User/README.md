# 四电机底层驱动说明

## 硬件映射

| 车轮 | TB6612 方向引脚 | PWM | 编码器 |
| --- | --- | --- | --- |
| 左前 FL | AIN1 / AIN2 | TIM5 CH1 | TIM1 |
| 右前 FR | BIN1 / BIN2 | TIM5 CH2 | TIM2 |
| 左后 BL | CIN1 / CIN2 | TIM5 CH3 | TIM3 |
| 右后 BR | DIN1 / DIN2 | TIM5 CH4 | TIM4 |

TIM9 保持为 HAL 的 1 kHz 系统时基。TIM10 使用 84-1 分频和 10000-1 自动重装值，在 84 MHz 定时器时钟下直接产生 100 Hz 中断，作为应用层控制信号。

电机方向系数在 `tb6612.h` 中设置，编码器方向系数、PPR 和减速比在 `encode.h` 中设置。上车前应逐轮悬空测试正负方向。

## 串口控制协议

USART6 使用 115200、8N1，以中断方式逐字节接收固定 5 字节数据包：

`@ MODE SPEED CRC8 #`

- `MODE`：0 停止、1 前进、2 后退、3 左移、4 右移、5 左旋、6 右旋。
- `SPEED`：停止模式必须为 0；运动模式可选 1、2、3，分别对应 100、200、300 RPM。
- `CRC8`：对前三个字节计算，初值 `0x00`，多项式 `0x07`。
- 连续 300 ms 没有收到合法数据包时，四轮目标转速自动清零。

串口中断只负责组包，`ReceiveTargetRPMTask` 每 10 ms 校验最新数据并更新四轮目标转速。四轮目标值以一个原子快照交给速度采样任务，避免任务抢占时混用两条指令的数据。

## 速度环

`app_task.c` 使用 100 Hz 固定周期执行四路独立速度控制。四路控制器均使用 `Lib/CMSIS-DSP-1.17.0` 中的 `arm_pid_instance_f32`，`arm_pid_f32()` 的返回值直接作为电机输出，不再叠加目标 RPM，之后只做电机最大 RPM 限幅。目标 RPM 为 0 或目标方向反转时复位对应 PID 状态。

当前代码中的参数为 `SPEED_PID_KP = 0.7`、`SPEED_PID_KI = 0.2`、`SPEED_PID_KD = 0`。`app_task.c` 会按 100 Hz 控制频率换算积分系数。编码器方向、PPR、减速比和电机最大 RPM 仍需根据具体实车标定；这些仓库参数只能作为调试起点，不能视为对当前车辆的最终性能保证。

F401 底盘已经完成四轮闭环和直线运行测试。当前 `main` 默认将四个车轮目标速度设为 100 RPM，并以 100 Hz 执行四路独立速度闭环；该默认配置已经完成编译、烧录和实车复测。F407→F401 的串口收发与解析代码已经实现，但因团队自制板串口链路的硬件故障尚未完成端到端验证；启用方法与安全测试步骤见仓库根目录 [`README.md`](../README.md)。
